Project untuk mengompres berbagai jenis file agar ukuran file menjadi lebih kecil.
Project ini masih dalam tahap pengembangan dan dibuat sebagai latihan untuk belajar membuat project di GitHub.

Rencana file yang ingin didukung:

JPG / JPEG
PNG
GIF
MP4
MP3
WebP
dan format lainnya

Beberapa fitur yang ingin dibuat:

- Kompres file
- Mengubah format file
- Memproses beberapa file sekaligus
- Melihat ukuran file sebelum dan sesudah dikompres
- Memilih tingkat kualitas kompresi


Catatan

Project ini masih dibuat dan kemungkinan akan banyak berubah selama proses pengembangan.
