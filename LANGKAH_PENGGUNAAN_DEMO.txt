A. PERSIAPAN SEBELUM RECORDING (CHECKLIST 1 MENIT)
--------------------------------------------------------------------------------
1. Pastikan Database & Server sudah menyala:
   - MySQL XAMPP aktif (Port 3306)
   - Backend API aktif di http://localhost:5000
   - Frontend aktif di http://localhost:5173

2. Buka Browser (Chrome / Edge):
   - TAB 1 (Mahasiswa) : http://localhost:5173
   - TAB 2 (Penjual)   : Klik tombol "Penjual" di pojok kanan atas (atau http://localhost:5173/seller)
   - TAB 3 (Display TV): http://localhost:5173/seller/display

3. Siapkan 1 jendela Terminal / PowerShell di folder backend untuk Unit Test:
   cd C:\Users\VIVOBOOK\Downloads\RPL\backend

--------------------------------------------------------------------------------
B. LANGKAH-LANGKAH REKAMAN & CONTOH NARASI (ACTION & SPEECH)
--------------------------------------------------------------------------------

[BAGIAN 1: PEMBUKAAN (0:00 - 0:30)]
- Aksi: Buka TAB 1 (Halaman Menu Mahasiswa).
- Narasi yang bisa diucapkan:
  "Halo, perkenalkan saya [Nama Anda]. Pada kesempatan kali ini saya akan
   mendemonstrasikan aplikasi Sistem Antrean Kantin (KantinQueue) versi final 
   untuk memenuhi tugas Rekayasa Perangkat Lunak.
   Aplikasi ini memiliki 3 area utama:
   1. Sisi Mahasiswa (Pemesanan menu & pembayaran QRIS),
   2. Sisi Penjual (Pengaturan QRIS toko, verifikasi bayar, masak, & kelola menu),
   3. Layar Display TV Kantin (Papan monitor antrean & info ketersediaan menu)."


[BAGIAN 2: MAHASISWA MEMILIH MENU & KERANJANG (0:30 - 1:15)]
- Aksi:
  1. Tunjukkan halaman katalog menu.
  2. Klik tombol filter kategori: "Makanan", lalu "Minuman", lalu kembali ke "Semua".
  3. Coba ketik di kolom pencarian: "Goreng" -> menu otomatis tersaring.
  4. Hapus teks pencarian.
  5. Klik tombol "+ Tambah" pada "Nasi Goreng Spesial" (Rp 15.000).
  6. Klik tombol "+ Tambah" pada "Es Teh Manis Jumbo" (Rp 4.000).
  7. Klik tab "Keranjang" di navbar atas (terlihat badge angka 2).
  8. Di halaman Keranjang, coba klik tombol "+" pada Es Teh Manis jadi 2 porsi.
  9. Tunjukkan kalkulasi Subtotal dan Total Pembayaran terhitung otomatis secara presisi.
  10. Tunjukkan bahwa pilihan menu tetap tersimpan aman di keranjang meskipun berpindah tab.
- Narasi yang bisa diucapkan:
  "Pertama, di sisi mahasiswa, pengguna dapat melihat daftar menu yang tersedia 
   beserta harga dan kategorinya. Kita bisa menyaring menu berdasarkan kategori 
   atau mencarinya lewat kolom pencarian. Di sini saya memilih 1 Nasi Goreng dan 
   2 Es Teh Manis. Pilihan menu mahasiswa tersimpan stabil di dalam keranjang 
   dan total harga terkalkulasi otomatis secara real-time."


[BAGIAN 3: CHECKOUT & PEMBAYARAN QRIS (1:15 - 2:00)]
- Aksi:
  1. Klik tombol "Lanjut Bayar QRIS".
  2. Tunjukkan tampilan instruksi pembayaran: Muncul QR Code QRIS (foto QR resmi dari penjual 
     tanpa NMID), nomor pesanan (contoh: ORD-20261020-xxxx), dan total tagihan yang sesuai.
  3. Di kolom bukti bayar / catatan (opsional), Anda bisa ketik: "Sudah bayar via BCA".
  4. Klik tombol hijau "Saya Sudah Bayar (Konfirmasi)".
  5. Klik tombol biru "Pantau Status Antrean".
  6. Tunjukkan bahwa status saat ini adalah: "Menunggu Verifikasi Pembayaran dari Penjual".
- Narasi yang bisa diucapkan:
  "Selanjutnya mahasiswa melakukan checkout. Sistem menerbitkan instruksi pembayaran QRIS 
   dengan total pembayaran yang sesuai. Setelah mentransfer, mahasiswa mengklik 
   konfirmasi sudah bayar. Status pesanan saat ini berada dalam tahap menunggu 
   verifikasi dari penjual kantin."


[BAGIAN 4: SISTEM KEAMANAN PENJUAL (POP-UP PASSWORD) (2:00 - 2:40)]
- Aksi:
  1. Klik tombol switch "Penjual" di pojok kanan atas navbar.
  2. Tunjukkan bahwa muncul POP-UP MODAL KEAMANAN:
     - Jika pertama kali: Muncul "Buat Password Penjual".
       Tunjukkan peringatan: "Wajib catat password karena tidak ada opsi lupa password!".
       Ketik password (misal: "admin123"), konfirmasi, lalu klik "Simpan & Masuk".
     - Jika sudah ada password: Masukkan password lalu klik "Buka Sisi Penjual".
  3. Tunjukkan bahwa mahasiswa tidak bisa sembarangan masuk ke sisi penjual.
- Narasi yang bisa diucapkan:
  "Sisi penjual dan layar display dilindungi oleh sistem keamanan password 
   sehingga mahasiswa tidak dapat mengaksesnya sembarangan. Saat pertama kali masuk, 
   penjual diminta membuat password baru yang wajib dicatat karena sistem tidak 
   menyediakan opsi lupa password demi keamanan kasir kantin."


[BAGIAN 5: PENJUAL UNGGAH QR CODE & VERIFIKASI BAYAR (2:40 - 3:25)]
- Aksi:
  1. Tunjukkan kartu "QR Code Pembayaran Kantin (QRIS)" di bagian atas dashboard penjual.
     Sebutkan bahwa penjual bisa mengunggah foto QR Code tokonya sendiri dalam format .jpg atau .png.
  2. Di tab "Pesanan Masuk", tunjukkan pesanan mahasiswa tadi.
  3. Tunjukkan rincian item pesanannya.
  4. Klik tombol hijau "Setujui Pembayaran".
  5. Tunjukkan bahwa sistem langsung menerbitkan NOMOR ANTREAN resmi (misal: A-001) 
     dan status pesanan otomatis berganti menjadi "Dikonfirmasi / Menunggu Dimasak".
- Narasi yang bisa diucapkan:
  "Di dashboard penjual, terdapat fitur bagi penjual untuk mengunggah foto QR Code tokonya 
   sendiri dalam format JPG atau PNG yang langsung digunakan mahasiswa saat checkout. 
   Saat penjual memeriksa pesanan dan mengklik 'Setujui Pembayaran', sistem secara otomatis 
   menerbitkan nomor antrean sekuensial unik, yaitu nomor A-001."


[BAGIAN 6: PROSES MASAK & LAYAR DISPLAY TV (ANTREAN & MENU) (3:25 - 4:15)]
- Aksi:
  1. Klik tombol "Mulai Siapkan / Masak Pesanan" (status berubah jadi PREPARING).
  2. Buka tab "Layar Display Monitor" (atau http://localhost:5173/seller/display).
  3. Tunjukkan 3 mode tampilan di Layar Display TV:
     - Mode "Layar Bersama (Split)": Menampilkan nomor antrean di sebelah kiri dan 
       ketersediaan stok menu (Tersedia / Habis) di sebelah kanan!
     - Mode "Ketersediaan Menu": Menampilkan seluruh menu dengan badge 'Siap Dipesan' vs 'Sold Out'.
     - Mode "Monitor Antrean": Menampilkan kolom 'Sedang Disiapkan' dan 'Silakan Ambil'.
  4. Kembali ke pesanan penjual, klik "Tandai Siap Diambil di Konter".
  5. Tunjukkan di Layar Display bahwa nomor A-001 langsung berpindah ke kolom hijau 
     "SILAKAN AMBIL (SIAP)".
- Narasi yang bisa diucapkan:
  "Pada Layar Display Monitor TV kantin, tersedia opsi untuk menampilkan antrean sekaligus 
   papan ketersediaan menu real-time bagi mahasiswa. Nomor antrean berpindah otomatis 
   dari 'Sedang Disiapkan' ke 'Silakan Ambil' saat makanan selesai dimasak."


[BAGIAN 7: SELESAI, GANTI PASSWORD, & KEMBALI KE MAHASISWA (4:15 - 4:40)]
- Aksi:
  1. Di sisi Penjual, klik "Pesanan Selesai Diambil".
  2. Tunjukkan tombol "Ganti Password" di navbar penjual untuk memperbarui kata sandi.
  3. Klik tombol "Mahasiswa" di pojok kanan atas untuk kembali ke mode pembeli dengan satu klik.
- Narasi yang bisa diucapkan:
  "Setelah pesanan diserahkan, penjual menandai selesai. Penjual juga memiliki opsi 
   untuk mengganti password kapan saja, dan cukup mengklik tombol Mahasiswa di header 
   untuk kembali ke mode pembeli dengan cepat."


[BAGIAN 8: BUKTI UNIT TEST & PENUTUP (4:40 - 5:00)]
- Aksi:
  1. Buka jendela Terminal / PowerShell di folder backend.
  2. Jalankan perintah: npm test
  3. Tunjukkan bahwa seluruh 5 file unit test (order, queue, payment, menu, auth) 
     berhasil lulus 100% (ALL PASSED: 26 assertions).
- Narasi yang bisa diucapkan:
  "Seluruh aturan bisnis telah diuji menggunakan 5 file unit test dan lulus 100%. 
   Demikian demonstrasi dari MVP Sistem Antrean Kantin (KantinQueue). Terima kasih!"

--------------------------------------------------------------------------------
C. TIPS TAMBAHAN AGAR REKAMAN MAKSIMAL
--------------------------------------------------------------------------------
1. Gunakan mode fullscreen browser (tekan F11) saat menampilkan Layar Display TV.
2. Berikan jeda 1-2 detik saat status antrean berubah agar terlihat jelas di video.
